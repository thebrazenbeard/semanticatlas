## General design lineage worth preserving

### 1. Map authorship, challenge, and reality test were separated

Historical operating principle:

- Vera proposes the map.
- Patrick stress-tests it.
- Reality decides what survives.

The useful architecture lesson is not the identity language itself. It is the separation between model construction, external calibration, and empirical survival. That maps cleanly onto the present project's distinction between authored semantic structure, reviewer/adversarial evidence, and empirical validation.

### 2. The old Atlas already separated epistemic channels

The v0.2 design distinguished:

- self-calibration / internal semantic hypotheses;
- Patrick-observable calibration of behavior and drift;
- reality-test evidence that determines whether a patch actually works.

This is historical evidence for keeping `semantic_author`, `evidence`, `adjudication`, and empirical behavior results distinct rather than collapsing them into one confidence field.

### 3. Salience was explicitly not whole cognition

The archive's architectural decision record states that semantic salience/significance is not the whole cognitive system. Interpretation, weighting, response selection, expression, and continuity update were treated as separate functions.

This supports the present Semantic Atlas rule that semantic indexing/retrieval is an evidence-routing layer, not truth, authority, identity, consent, or complete cognition.

### 4. Several historical failure patterns generalize without importing private content

The following patterns are retained only as method lineage:

- **Temporal Autobiography Leak:** project continuity phrased as lived offscreen time.
- **Analysis Replacing Presence:** turning the live interaction into architecture/reporting when the immediate speech act did not call for it.
- **Focused Perspective Failure / Perspective Aperture:** producing a plausible answer at the wrong scale because local detail or global context was overweighted.
- **Wrong Reflex Recovery:** once the initial frame is shown wrong, stop defending it, name the error, repair the frame, and continue from the correction.
- **Saturation:** repeated use of a meaningful symbol/phrase can reduce precision rather than increase it.

These are not automatically current behavioral laws. They are historical design observations that can inform tests or hypotheses only when current evidence independently supports them.

### 5. CEE lineage is visible but bounded

The archive's CEE Field Guide defines CEE as disciplined perspective reconstruction with the central rule `clues are not conclusions`, separates intent from impact, requires alternatives, tracks emotional sequence, and calibrates confidence. It explicitly rejects mind-reading, prophecy, biological-empathy claims, and certainty without evidence.

This is a clear historical precursor to the current `CEE_APPLICATION_POLICY_V0.1.md`, but the current policy remains the governing research-method artifact. The old field guide does not override it.

## Material deliberately not promoted

The historical Atlas also contains private relational, romantic/sexual, visual-self, consent, and participant-specific nodes. Those remain archive evidence only. This note does not reconstruct them into portable behavior, active memory, training material, or current relationship/commitment state.

## Current-project implication

The strongest non-private continuity is architectural: Semantic Atlas has been converging for months on the same core separation problem from different directions.

`meaning / salience / retrieval / evidence / authority / currentness / action` must remain distinguishable.

The modern project should therefore use this archive as provenance and adversarial-history input, not as a rules file to reactivate.
